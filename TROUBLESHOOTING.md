# Диагностика проблем с 3D симулятором

## Симптом: Страница не открывается или белый экран

### Шаг 1: Проверьте консоль браузера

1. Откройте https://xrayhub.ru/positioning
2. Нажмите F12 (или Ctrl+Shift+I)
3. Перейдите на вкладку "Console"
4. Найдите красные ошибки

### Распространенные ошибки:

#### 1. CORS Error
```
Access to fetch at 'https://s3.ru1.storage.beget.cloud/...' from origin 'https://xrayhub.ru'
has been blocked by CORS policy
```

**Решение:** Настройте CORS для S3 bucket:
- Зайдите в панель Beget S3
- Добавьте CORS правило:
```json
[
  {
    "AllowedOrigins": ["https://xrayhub.ru", "http://localhost:5173"],
    "AllowedMethods": ["GET", "HEAD"],
    "AllowedHeaders": ["*"],
    "MaxAgeSeconds": 3600
  }
]
```

#### 2. 403 Forbidden
```
GET https://s3.ru1.storage.beget.cloud/0f31e7f56d88-xrayhub/teeth_upper.glb 403
```

**Решение:** Настройте публичный доступ к файлам:
- В панели Beget S3 сделайте файлы публичными
- Или настройте Bucket Policy (см. S3_SETUP.md)

#### 3. Network Error
```
TypeError: Failed to fetch
```

**Возможные причины:**
- Проблемы с интернетом
- DNS не резолвится
- Beget S3 недоступен

**Проверка:** Откройте URL модели напрямую:
```
https://s3.ru1.storage.beget.cloud/0f31e7f56d88-xrayhub/teeth_upper.glb
```

Если файл скачивается - проблема в CORS.
Если 403 - проблема в доступе.

### Шаг 2: Очистите кеш браузера

1. Нажмите Ctrl+Shift+Delete
2. Выберите "Изображения и файлы в кеше"
3. Нажмите "Удалить данные"
4. Перезагрузите страницу (Ctrl+F5)

### Шаг 3: Проверьте, что деплой завершился

GitHub Actions должен завершить деплой (~3-5 минут после push).

Проверьте в репозитории:
- Вкладка "Actions"
- Последний workflow должен быть зелёным ✓

### Шаг 4: Визуальная диагностика

После последнего обновления:
- **Зелёные кубики** (wireframe) = модели загружаются
- **Красные кубики** (wireframe) = ошибка загрузки модели
- **Синяя панель** вверху показывает URL S3

Если видны красные кубики - проблема с доступом к S3.

## Тестирование локально

```bash
npm run dev
```

Откройте http://localhost:5173/positioning

Если локально работает, а на production нет - проблема в деплое или настройках сервера.

## Быстрая проверка доступности моделей

Выполните в терминале:

```bash
curl -I https://s3.ru1.storage.beget.cloud/0f31e7f56d88-xrayhub/teeth_upper.glb
```

**Ожидаемый результат:**
```
HTTP/1.1 200 OK
Content-Type: model/gltf-binary
```

**Проблема - 403:**
```
HTTP/1.1 403 Forbidden
```
→ Настройте публичный доступ к bucket

**Проблема - CORS:**
Файл доступен по прямой ссылке, но не загружается в браузере
→ Настройте CORS

## Контакты для помощи

Если проблема не решается:
1. Сделайте скриншот консоли браузера (F12)
2. Сделайте скриншот вкладки Network с запросом к S3
3. Опишите, что видите на странице
