# Приложение для формы №3-ДОЗ

React-приложение для ведения формы №3-ДОЗ "Учет коллективных доз облучения пациентов при рентгенологических исследованиях"

## Реализованный MVP (v1.0)

### Основные возможности

- Создание отчётов для стоматологических клиник
- Ввод информации об организации и ответственных лицах
- Добавление процедур из справочника (6 базовых типов для стоматологии)
- Автоматический расчёт коллективных доз (чел·мГр)
- Валидация доз по референсным уровням (НРБ-99/2009, МУК 2.6.1.3584-19)
- Экспорт отчёта в формат Excel

### 3D Симулятор позиционирования (v2.0)

- Интерактивный 3D симулятор для обучения правильному позиционированию при рентгенологических исследованиях
- 7 анатомических моделей (зубы, десны, гортань, язык, датчик)
- Система универсальных трансформаций (Pivot/Object) для точного позиционирования
- Визуализация рентгеновского света с направлением и конусом освещения
- Настройка прозрачности для просмотра внутренних структур
- Отображение координат в реальном времени
- Адаптивный дизайн для мобильных устройств

### Справочник процедур для стоматологии

1. Интраоральный снимок (зуб) — 0.15 мГр
2. Интраоральный снимок (сегмент) — 0.5 мГр
3. ОПТГ (панорамный снимок) — 0.03 мГр
4. КТ одной челюсти — 0.1 мГр
5. КТ обеих челюстей — 0.15 мГр
6. Цефалометрия — 0.025 мГр

### Автоматический деплой на GitHub Pages

Приложение автоматически деплоится на GitHub Pages при каждом push в ветки:
- `main`
- `claude/radiation-dose-reporting-app-RM8Cf`

**Настройка GitHub Pages (требуется один раз):**

1. Перейдите в **Settings** → **Pages** вашего репозитория
2. В разделе **Source** выберите **GitHub Actions**
3. Сохраните настройки

После этого GitHub Actions автоматически соберёт и задеплоит приложение.

## Использование

1. **Создание отчёта**: Заполните форму с данными организации и ответственных лиц
2. **Добавление процедур**: Выберите тип процедуры, укажите количество и возрастную группу
3. **Проверка данных**: Система автоматически рассчитает коллективные дозы и предупредит о превышении референсных уровней
4. **Экспорт**: Скачайте готовый отчёт в формате Excel
