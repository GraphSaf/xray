# 3D Models for Dental Simulator

## Нужные модели:

### 1. Зубы и челюсть (приоритет 1)
- Формат: GLTF/GLB
- Содержание: Верхняя и нижняя челюсть с зубами
- Требования: Анатомически корректная, текстуры

### 2. Голова пациента (приоритет 2)
- Формат: GLTF/GLB
- Содержание: Простая голова человека
- Можно использовать текущую sphere, если не найдется

### 3. Рентген-аппарат (приоритет 3)
- Формат: GLTF/GLB
- Содержание: Дентальный рентген с тубусом
- Можно использовать текущие примитивы, если не найдется

## Где искать:

1. **Sketchfab** - https://sketchfab.com/search?q=teeth+dental
2. **Free3D** - https://free3d.com/3d-models/teeth
3. **TurboSquid** - https://www.turbosquid.com/Search/3D-Models/free/teeth
4. **CGTrader** - https://www.cgtrader.com/free-3d-models/character/anatomy/teeth
